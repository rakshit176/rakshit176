### 🔥 Featured projects

#### 🔐 Cisco ASA firewall validation — LLM Knowledge Distillation
> **Stack:** GPT-4 · PyTorch · BERT · LangGraph · Neo4j · Qdrant · AWS ECS · Lambda · SQS
>
> GPT-4 Teacher annotates 50K+ ASA configs with soft labels + chain-of-thought reasoning from Cisco vendor guides. AI agents orchestrate KL-divergence distillation into 3 student models — conflict classifier, syntax validator, risk scorer. **Zero LLM calls at inference.**
>
> **Result:** 4+ hours → 2–5 seconds · Fortune 500 scale · 200+ firewalls · 10× faster migration

#### 🔍 GSC enterprise AI search engine

>
> **Result:** 10K+ QPD · p95 <300ms · 99.9% uptime · *(public release pending)*
